🛠️ Quy Trình Làm Sạch Chi Tiết
Bước 1: Ánh Xạ Cột (Tiki → PriceWise)
Tiki (Thô)           →  PriceWise (Chuẩn)
├─ id                →  ma_san_pham
├─ name              →  ten_san_pham
├─ primary_category_path (path/path/name) → nganh_hang (lấy phần cuối)
├─ seller            →  shop
├─ price             →  gia
├─ original_price    →  gia_goc
├─ discount_rate/100 →  ty_le_giam
├─ quantity_sold     →  luot_ban
├─ rating_average    →  danh_gia
└─ url_path          →  url (với tiền tố https://tiki.vn/)
Bước 2: Xử Lý Thiếu Dữ Liệu (NULL)
Cột bắt buộc (xóa dòng):
  ✓ ma_san_pham, ten_san_pham, gia, danh_gia, url

Cột phụ (điền mặc định):
  ✓ shop           → "Tiki"
  ✓ nganh_hang     → "Chưa phân loại"
  ✓ gia_goc        → = gia (nếu không có)
  ✓ ty_le_giam     → 0

Xóa trùng lặp:
  ✓ Dựa trên ma_san_pham (giữ dòng đầu)

Bước 3: Ép Kiểu Dữ Liệu
Numeric:
  ✓ gia, gia_goc → float64
  ✓ ty_le_giam   → float64 [clipped 0→1]
  ✓ luot_ban     → int64
  ✓ danh_gia     → float64 [clipped 0→5]

Categorical:
  ✓ nganh_hang, shop → category (tiết kiệm RAM)

Validation:
  ✓ Giá phải > 0
  ✓ Đánh giá [0, 5]
  ✓ Tỷ lệ giảm [0, 1]
Bước 4: Phát Hiện Ngoại Lai
IQR Method:
  ✓ Q1 = 25th percentile
  ✓ Q3 = 75th percentile
  ✓ IQR = Q3 - Q1
  ✓ Bounds: [Q1 - 1.5×IQR, Q3 + 1.5×IQR]
  ✓ Phát hiện: 5 sản phẩm

Z-score Method:
  ✓ Z = |X - mean| / std
  ✓ Ngưỡng: |Z| > 3.0
  ✓ Phát hiện: 1 sản phẩm

Kết hợp:
  ✓ Gắn cờ: da_kiem_tra_gia_ao = True
  → Không xóa, giữ để phân tích "giảm giá ảo"
